# CS50x-Projects

A collection of projects completed as part of **CS50's Introduction to Artificial Intelligence with Python**, Harvard University's introductory course in artificial intelligence.

This repository documents the implementation of core AI algorithms and techniques, ranging from classical search methods and logical inference to machine learning, neural networks, and natural language processing.

---

## About the Course

CS50 AI introduces the fundamental ideas that underpin modern artificial intelligence and provides hands-on experience implementing them in Python.

Topics covered include:

* Search algorithms
* Knowledge representation
* Probabilistic reasoning
* Optimisation
* Machine learning
* Neural networks
* Natural language processing

## Project Overview

### 0. Search

Introduction to state-space search and pathfinding algorithms.

Projects explore:

* Breadth-First Search (BFS)
* Depth-First Search (DFS)
* A* Search
* Adversarial search and game-playing agents

Key takeaway: modelling problems as states and efficiently searching for optimal solutions.

---

### 1. Knowledge

Representing information using formal logic and drawing conclusions through inference.

Projects explore:

* Propositional logic
* Knowledge bases
* Logical entailment
* Automated reasoning

Key takeaway: enabling computers to reason from known facts.

---

### 2. Uncertainty

Making decisions when information is incomplete or probabilistic.

Projects explore:

* Probability theory
* Conditional probability
* Bayesian networks
* Inference under uncertainty

Key takeaway: reasoning effectively despite incomplete information.

---

### 3. Optimization

Finding high-quality solutions to complex problems with large search spaces.

Projects explore:

* Constraint Satisfaction Problems (CSPs)
* Local search techniques
* Optimisation strategies

Key takeaway: balancing computational efficiency with solution quality.

---

### 4. Learning

Teaching computers to identify patterns directly from data.

Projects explore:

* Supervised learning
* Classification
* Training and evaluation methods
* Predictive modelling

Key takeaway: building systems that improve performance through experience.

---

### 5. Neural Networks

Implementing machine learning models inspired by biological neural systems.

Projects explore:

* Artificial neural networks
* Deep learning fundamentals
* Image recognition applications

Key takeaway: constructing models capable of learning complex relationships in data.

---

### 6. Language

Applying AI techniques to human language.

Projects explore:

* Natural Language Processing (NLP)
* Parsing
* Information extraction
* Language modelling

Key takeaway: enabling computers to interpret and process human communication.
